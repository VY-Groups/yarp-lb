# Reference and license status

## OpenGSLB reference

OpenGSLB was consulted only to understand GSLB and DNS feature behavior. GatewayCore's DNSSEC NSEC3 implementation is independently implemented in C# against RFC 5155. GatewayCore does not use OpenGSLB modules.

The `gslb` branch contains the separate OpenGSLB project and its own license information. That reference is not GatewayCore's implementation or product license.

## GatewayCore ownership and licensing history

GatewayCore is intended as an owner-controlled proprietary product. Customer licensing and activation are deferred until the remaining software issues are complete.

The current checkout has no root `LICENSE` file. Earlier repository revisions included project-wide AGPL license text. This history should be reviewed before making distribution claims. This note records the owner's reference clarification and does not establish customer distribution terms.
