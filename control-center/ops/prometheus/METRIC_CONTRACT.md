Generated from the shipping Control Center `/gateway/metrics` endpoint. This list is machine-checked against REAL emitted metrics obtained through the management mTLS listener, not only C# text.

```metrics

```

`probe_ssl_earliest_cert_expiry` and `probe_success` are **external blackbox exporter** metrics, never product metrics. `up` is generated by Prometheus. Each external probe must be configured and tested before live alerts can be marked operational. Metrics are bound to the protected management interface in listener-isolation mode and require a trusted, allowlisted mTLS client. Legacy loopback-only serving remains for current 0.1 CI migration tests. Readiness is `GET /gateway/health/ready` on the data-plane socket; `/gateway/health` remains liveness, not backend readiness. The raw 0.0.4 histogram p99 is approximate; one-hour gate uses client-side exact percentiles from load generator.
